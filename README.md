# 사진 일괄 크기조절

**사진 여러 장과 PDF를 한 번에 같은 규격으로 맞춰주는 사내용 도구**

[![바로 써보기](https://img.shields.io/badge/바로_써보기-utou--photo.netlify.app-2563eb?style=for-the-badge)](https://utou-photo.netlify.app)

설치 없음 · 서버 없음 · 비용 없음 · 사진이 PC 밖으로 나가지 않음

</div>

---

## 이게 뭔가요

사진 수십 장을 **똑같은 크기, 똑같은 위치**로 맞춰야 할 때 한 장씩 포토샵을 여는 대신 쓰는 도구입니다.
사진을 화면에 끌어다 놓고 → 원하는 규격을 고르고 → 버튼 한 번이면 ZIP으로 나옵니다.

**PDF도 됩니다.** 한 쪽이 사진 한 장이 됩니다. 10쪽짜리 계약서면 이미지 10장이 나옵니다.

> **HTML 파일 하나가 프로그램 전부입니다.** 빌드도, 설치도, 서버도, 데이터베이스도 없습니다.
> 모든 처리가 브라우저 안에서 일어나므로 **사진이 어디로도 전송되지 않습니다.**

## 파일 구성

```
사진일괄조절.html      ← 본체. 이것 하나가 프로그램 전부입니다 (약 72KB)
preset.json           ← 회사 기본 규격. 같은 폴더에 있으면 자동으로 읽습니다
batch_resize.py       ← 폴더 통째로 돌리는 파이썬 버전 (Pillow 필요, PDF 미지원)

배포용/               ← 이 폴더를 통째로 올리면 배포 끝
  index.html          ← 사진일괄조절.html 의 복사본 (항상 같아야 합니다)
  preset.json
  pdf.min.mjs         ← PDF.js (Apache-2.0)
  pdf.worker.min.mjs  ← PDF.js (Apache-2.0)
```

> ⚠️ `사진일괄조절.html` 을 고쳤으면 **반드시** `배포용/index.html` 로 복사하세요.
> ```bash
> cp 사진일괄조절.html 배포용/index.html
> ```

## 어떻게 돌아가나

```
settings()  화면의 설정을 객체 하나로 읽음
    ↓
layout()    어디에 얼마만 한 크기로 그릴지 계산   ← 결과를 좌우하는 중심
    ↓
render()    캔버스에 그림 (미리보기도 결과물도 같은 함수)
```

미리보기와 저장 결과가 **같은 길**을 쓰기 때문에 보이는 대로 나옵니다.

설정은 브라우저 `localStorage` 에 저장됩니다. 서버도 로그인도 없어서 **PC마다 따로** 쌓이고, 그래서 사람끼리 설정을 주고받는 **글자 코드** 기능이 있습니다.

자세한 구조는 [개발 이어받기 문서](HANDOFF.md)를 보세요.

## 개발 · 시험

빌드가 없으므로 고치고 브라우저에서 열면 끝입니다.
다만 **PDF 기능은 `file://` 로는 동작하지 않으니** 간단한 정적 서버로 띄우세요.

```bash
cd 배포용
python -m http.server 8791     # 또는 npx serve -p 8791
```

→ <http://127.0.0.1:8791>

> 💡 **자동화로 시험할 때는 브라우저 창을 앞에 두세요.**
> PDF.js는 화면 갱신 신호에 맞춰 그리기 때문에, 창이 가려져 있으면 PDF 변환이 영영 끝나지 않습니다. 버그가 아닙니다.
> 이것 말고도 걸려 넘어지기 쉬운 것들을 [HANDOFF.md의 「함정」](HANDOFF.md#6-함정-)에 모아 뒀습니다.

## 만들면서 정한 것들

이어받는 사람이 같은 길을 다시 헤매지 않도록 적어 둡니다. ([자세히](HANDOFF.md#5-이미-해봤다가-접은-것-))

- **유료 서비스를 쓰지 않습니다.** 처음부터의 조건이었습니다.
- **AI 배경제거(누끼)는 빼기로 했습니다.** 두 가지 방식을 시도했지만 품질이 안 나왔습니다. 대신 **피사체 크기 통일**을 넣었습니다.
- **로그인·서버가 없습니다.** 그래서 설정이 PC마다 따로 저장되고, 공유는 글자 코드로 합니다.
- **설명은 쉬운 말로.** 「긴 변 기준」 같은 표현은 알아듣기 어렵다는 피드백을 받아 그림 버튼과 풀어쓴 문장으로 바꿨습니다. 새 기능도 같은 기준을 지켜주세요.
